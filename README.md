# WorshipFlow Android

Build paralelo da **v52** para Android via GitHub Actions.

- A **v51 PWA** permanece separada e continua em produção.
- Este repositório gera um **APK de teste** sem publicar na Play Store.
- O código-fonte usado no build está compactado em `source.tgz.b64`.
- Arquivos locais privados, backups e a chave do YouTube não são enviados ao repositório.

O APK gerado aparece em **Actions → Build WorshipFlow APK → Artifacts**.
